# P01-B5 설정·정적 검사·실행 안내·Git 로컬 이력

2026-10-23 / 상태: 구현·검증 중

## 범위와 실행 순서

설계 v4, 구현 계획 P01-B5, 목표 G01·G07·G10을 따른다. 설정 예제와 비밀값 제외 → Checkstyle 및 기존 ESLint 확인 → 두 빌드 재현 → Git 초기화·로컬 이력 → 지정 검토 세션 검토·반영 순서다. DB·Compose·인증·업무 API와 P01-C1은 진행하지 않는다.

결정: 기존 저장소가 없으므로 현재 프로젝트를 초기화한다. worktree는 아직 만들지 않는다. 기존 B1~B4 소스·문서를 초기 기준점에 포함하며 시스템 도구와 기존 서버는 변경하지 않는다. 설정·문서 작업에는 구현을 그대로 반복하는 단위 테스트를 추가하지 않고 실제 정적 검사 실패 탐지와 빌드로 검증한다.

Checkstyle 3.6.0 플러그인(현재 엔진 9.3)을 validate에 연결한다. 최소 규칙은 탭 금지, 별표/미사용 import, 중괄호, 클래스·메서드 명명이다. 기존 Java 스타일을 크게 바꾸는 포맷터는 추가하지 않는다. Java 기능 테스트는 아직 없으며 정적 검사 성공을 JUnit 성공으로 표현하지 않는다. 기존 ESLint 설정은 유지한다.

설정 예제는 비밀값 없는 로컬 바인딩만 제공한다. 프런트는 필요한 환경 변수가 없어 설명만 둔다. VITE_*는 공개 값이며 서버 비밀값을 넣지 않는다. 실제 DB 설정은 C1이다.

## 검증 결과

- Java: Checkstyle 3.6.0 다운로드 후 clean verify 성공, 규칙 위반 0. 별표 import 임시 소스로 validate 실패(위반 1건)를 확인한 뒤 제거했고 offline clean verify도 성공했다. JUnit은 0건이다.
- React: npm ci로 162개 패키지 설치, typecheck·lint·build 성공(102 모듈). 미사용 변수 임시 소스로 lint 실패를 확인한 뒤 제거하고 다시 통과했다. 전체 Node 테스트는 68개 통과·실패/건너뜀 0이다.
- 제한된 실행: Maven Central DNS 실패와 프록시 테스트 localhost EACCES가 발생했다. 승인된 실행에서 동일 빌드·테스트가 통과했다. 이 실패는 제품 결함과 구분해 원본 로그를 보존했다.
- 로컬 설정 예제를 복사해 임시 포트 5577로 변경한 후 backend 작업 디렉터리에서 local 프로필로 JAR 실행: HTTP 200, `{"status":"UP"}`. 검사 도구가 처음에 Actuator 응답 바이트 배열을 문자열로 해석하지 못해 실패했으며 UTF-8 디코딩 후 통과했다. 제품 수정은 없었다. 직접 시작한 프로세스와 임시 설정 파일만 finally에서 정리했다.
- Git: main 초기화, 도구·캐시·빌드·IDE·로컬 설정·키 파일 제외 확인. 예제·잠금 파일·Wrapper는 추적 대상. 스테이징 파일의 키 패턴 검사에서 알려진 패턴 발견 0, 제외 대상 경로 0. 이는 모든 비밀 탐지를 보장하지 않는다. 원격 등록·push 없음.
- 기존 기능의 UI는 변경하지 않아 브라우저 재검사는 수행하지 않았다. B4의 68개 회귀 검사와 정적 빌드를 재실행했다. 사용자 직접 확인·학습 완료와 타 OS 실행은 미확인이다.

## 실행과 학습

[로컬 실행 안내](../local-development.md)에 실제 버전·도구 경로·설정 적용 방법·빌드 및 실행 명령을 정리했다. Checkstyle은 Java 소스 규칙, ESLint는 TS/React 소스 규칙이며 기능 테스트를 대신하지 않는다. 별표 import/미사용 변수를 넣었다가 제거하는 작은 실습을 제안한다. DB 설정은 C1까지 없다.

검토는 지정된 `검토 및 반영세션`에서 수행했다. B5-R1(P3)의 Unix Wrapper 실행 비트 지적을 반영해 Git index 100755를 확인했다. [검토 기록](P01-B5-review.md)을 따른다. 타 OS 실제 실행은 미검증이다. 로컬 이력은 최종 검토 후 기록한다.
