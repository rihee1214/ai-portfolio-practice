# P11-A 판매자 정산 원장과 주간 모의 지급

후속 P11-B의 현재 승인 계약과 로컬·모의 범위 최종 수용·미커밋 인계는 [P11-B 구현·검증 기록](P11-B.md)을 따른다. 2026-11-11 최신 사용자 지시는 아래 후속 대화의 판매자 직접 승인·무회수·30일 기한·첫 부분 환불 배송비 전액 반환안을 대체한다. A의 최종 수용·소스·실행 증거는 변경하지 않는다.

2026-11-11 기존 검토 근거와 동일 소스 원보고서 대조로 로컬 범위 최종 수용. [P11 계획](../implementation-plan.md#13-p11-정산알림대시보드운영-설정)의 첫 작업으로 F17·AC15와 AC10·AC13의 정산 경계를 다룬다. [P10-E 최종 인계](P10-E.md#p11-인계-계약)와 [P09-G 금융 인계](P09-G.md)의 원 거래를 대조했다. 아래 세 정책과 지연 지급의 마감 기준을 사용자가 승인했다.

일부 수량의 미결 환불을 어느 범위까지 보류할지와 음수 잔액 이월은 B의 결정이다. A의 정상 지급 사례는 보류가 없는 거래로 검증하고, 지급 경로에는 미결 거래가 흘러들지 않아야 한다. C의 수신자·과거 통지와 D의 지표 기간 귀속은 해당 작업에서 결정한다.

## 기존 검토세션의 중간 판정

첫 판정은 수정 필요였다. [검토 입력 25개](../../.local-tools/p11-a-dev-20261110/review-inputs.json)의 해시가 일치했다. 미결 클레임 없는 일요일 상품이 월요일 배송 판단에 따라 이동하는 경우, 해당 주에 무관한 보류나 검토 뒤 추가된 원인이 검토·지급 결과를 다르게 만드는 경우, 원장 ID·문자열 키만 바꾼 원 수량 중복, V116 이행 검사의 매대 FK 누락을 확인했다. UNKNOWN 단독 보류와 잔여 1원 수수료 반환도 독립적으로 구별하는 assertion이 필요했다.

[두 번째 입력](../../.local-tools/p11-a-dev-20261110/review-inputs2.json) 26개 파일을 같은 검토세션에서 대조했다. 검토·지급 전 해당 주 전체 명세 대조, 원 수량 중복 방지, 기존 주문 이행 검사 준비는 구현상 해소 판정이었다.
