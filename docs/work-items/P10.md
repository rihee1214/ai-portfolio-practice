각 단계의 assertion 이름은 계획 식별자이며 아직 존재/실행한 테스트가 아니다. 구현 시 정확한 파일·메서드·기대/실제 결과로 이 문서와 단계 문서를 갱신한다. `backend/src/test/java/com/example/marketplace/dbtest/`에 업무별 IT 소유권을 배치하고 `verification/db-groups.json`, `db-test-baseline.json`, `required-tests.json`, `required-frontend.json`, `required-browser.json`에 새 계약과 소비 영향을 함께 등록한다. 준비용 주문/인증/미디어 소비도 영향표에 포함한다. 구현 전 미등록 계약 이름을 실행 가능한 선택 옵션처럼 쓰지 않는다.

개발 집중 실행은 등록 후 `-ChangedContracts` 또는 검토한 정확한 `-DbGroups`를 쓰며 제외 이유를 기록한다. 도메인 범위가 명확하면 선택 통과+독립 범위 검토로 단계 완료 가능하나 인증·공유 스키마·공통 미디어/fixture/하네스 등 넓은 동작 변경 또는 영향 누락이면 무선택 전체가 필요하다. **E의 P10 통합 마감은 새 증거 경로의 무선택 `./verify.ps1 -Offline` 전체 근거가 필수**다. 개발·독립에서 기계적으로 두 번 실행하지 않는다.

전체 진입 전 제약/소비 assertion, 변경 fixture의 실제 업무 본문 도달, 정상·경계·실패 집중 근거, 준비 오류/필수 결함 잔여, 등록/수집/옵션을 기존 완료표로 확인한다. 준비 시각과 worker 현재 시각/lease를 혼용하지 않고 저장 due/current token/lease의 F/G 패턴을 재사용한다. 명시적 데이터·선택을 사용하고 임의 sleep/timeout 확대·overflow 숨김·문구/필수 assertion 제거로 통과시키지 않는다. 새 DB·미디어·증거 경로를 사용하고 기존 서버·DB·미디어·실패를 보존한다.

## 검토·인계와 기록

기존 구현 담당과 검토세션 `01a189b0-2b5e-70d3-8276-214a42f6570d`를 유지한다. 정책/공개 계약 판단, 연결된 업무 묶음이나 후속 재작업 위험 경계의 중간 검토, 완료표와 개발 증거를 갖춘 최종 검토를 구분한다. 새 쟁점·파일/hash·관련 증거·미완료 범위를 전달하며 쟁점 없는 내부 수정을 묶는다. 각 단계 인계는 선행 계약 변경 여부·전체 완료표·선택/제외·실제 명령/경로·소스·지적 해결·미검증/차단을 다음 문서에 연결한다. 실패는 RED/제품/준비/환경/필수 미선택을 구분하고 가설·수정·실패/영향 재검증·측정한 실행 시간을 남긴다. 미측정 시간을 구현/검토/대기로 배분하지 않는다.

현재 계획에 적용한 스킬은 Superpowers 7.0.1 `writing-plans`이며 기존 요구/설계·G 인계와 프로젝트 업무 묶음/양식을 재사용한다. 기본 별도 plans/spec 경로·새 담당·task별 커밋·추가 승인 절차는 적용하지 않는다. 이번에는 문서 정적 확인·기존 세션 계획 검토만 수행하며 제품/테스트/하네스/DB/환경을 변경하거나 검사를 실행하지 않는다.

검토6파일의 링크20건·fence/대체문자 확인도 기존 세션이 수행했다. 별도 독립 실행은 실행 동작 없는 문서 변경이므로 불필요하다. 하네스/제품 테스트 실행0이며 P10 선택/전체 PASS를 주장하지 않는다. 미정 정책은 위 표의 구현 진입 의존으로 남고, 이번 계획 수용이 사용자 정책 결정이나 구현 승인이 아니다.

정적 도구 준비 오류도 구분한다. Windows에서 `rg`에 glob 파일명을 직접 전달한 조회는 경로 오류였고, 해시 목록 PowerShell의 `foreach` 뒤 파이프는 구문 오류였다. 후자는 배열로 감싸 재실행해 확인했다(실패 명령 도구 관측0.6408317초, 수정 명령0.7961798초; 업무 테스트/전체 검증 시간 아님). 제품·fixture 결함이나 과거 지연 원인으로 해석하지 않는다. 그 외 문서 작성/검토/대기 시간을 임의 배분하지 않는다.

F07/G08 BLOCKED·P09 전체 미완료를 유지한다. 구현·테스트·하네스·DB·환경·전역 스킬 변경, 커밋·푸시·배포·P11 구현은 수행하지 않았다. 실제 사용자 화면 확인은 미실행이다. 다음에는 승인된 단계 범위의 실제 미완료 지점과 정책 의존을 확인한 뒤 시작한다.
