# 홈 공통 헤더 회원 링크 독립 검토

2026-10-24 / 기준 `f96638e` 이후 작업 트리 / 상태: **요청 범위 검토·독립 브라우저 검증 완료, 필수 수정 잔여 없음**

## 범위와 정적 검토

사용자 요청에 따라 [작업 문서](header-auth-links.md)와 SiteLayout.tsx, styles.css, e2e/browser.spec.ts의 변경을 직접 대조했다. 기존 홈에는 ‘내 계정 · 로그인’만 있었고 회원가입 링크는 인증 화면 안에 있었다.

- 공통 헤더의 ‘회원 서비스’ 내비게이션에서 로그인 `/login`, 회원가입 `/signup`, 내 계정 `/account`를 직접 제공한다. App.tsx의 기존 경로와 실제 도착 화면이 일치한다.
- 기존 내 계정 경로를 유지하며 인증 조회·세션 로직·권한 규칙은 추가하거나 변경하지 않았다. 로그인 상태에서도 세 링크를 표시하는 최소 변경이다.
- 링크 묶음은 flex 줄바꿈과 12px 간격을 사용한다. 테스트는 홈에서 각 링크의 표시·href·키보드 Enter 이동·도착 제목·가로 넘침을 확인한다.
- 백엔드·DB·P03-B 구현 변경은 없다.

## 독립 실행 결과

frontend 디렉터리에서 프로젝트 로컬 Node로 `node_modules/@playwright/test/cli.js test --grep '홈 공통 헤더'`를 직접 실행했다. PATH에는 로컬 Node를 추가하고 E2E_API_JAR에는 `.local-tools/p03-a-browser-fixed/build/marketplace-api-0.0.1-SNAPSHOT.jar`를 지정했다.

**종료 코드 0, desktop 1개 + mobile 1개 = 2개 통과.** 각 사례가 홈에서 세 링크를 각각 확인한다. [최종 독립 실행 로그](evidence/header-auth-links-review-browser.txt)를 보존한다.

처음에는 npm.ps1의 작업 디렉터리 변경 때문에 상대 로그 경로를 찾지 못했다. 절대 경로로 교정한 다음에는 npm 래퍼를 통한 `--grep` 전달이 제대로 되지 않아 `No tests found`로 종료했다. Playwright 직접 호출로 해결했으며 두 시도는 제품 테스트 실패나 성공 증거로 계산하지 않는다.

개발세션의 타입·린트·빌드·단위 76개 통과 보고와 [브라우저 18개 실행 로그](evidence/header-auth-links-browser.txt)는 별도 개발 검증이다. 이 세션은 해당 변경을 정적으로 검토하고 위의 핵심 브라우저 2개를 직접 재실행했다.

## 보존 및 검증 한계

기존 서버를 시작·종료하지 않았다. Playwright는 기존 서버를 재사용하지 않는 별도 포트 18080·24174·24175를 사용하고 자체 테스트 서버만 정리한다. 이 검사는 DB 자동 구성을 제외한 테스트 프로필을 사용하며 DB 생성·삭제·초기화·데이터 변경 명령을 실행하지 않았다. 기존 DB와 새 검증 DB는 유지한다. 이번에는 DB 내용 해시 비교를 별도로 반복하지 않았다.

이번 결과는 개발 테스트 화면에서의 링크 발견·이동 검증이다. 5174의 기존 화면 제공 상태, 새 회원가입 완료·로그인 성공, 로그인된 세션에서의 브라우저 재검증, 실제 모바일 기기, 사용자 직접 이해·실습은 이번에 검증하지 않았다. 빌드 미리보기에서의 세 링크 이동도 독립 재검증 범위에 포함하지 않는다. P03-B 및 다음 작업은 진행하지 않았다.

## 개념과 직접 수정 예시

`SiteLayout`은 공통 헤더와 자식 화면을 보여주는 `Outlet`을 제공한다. 사용자가 `Link`를 누르면 React Router가 URL에 맞는 기존 `AuthForm` 또는 `AccountPage`를 렌더링한다. 링크를 추가하는 것과 회원가입 API를 실행하는 것은 별개다.

작은 실습으로 SiteLayout의 링크 글자 ‘회원가입’을 ‘가입하기’로 바꾸고 `/signup` 목적지는 유지해 볼 수 있다. 브라우저 검사도 새 접근 가능한 이름에 맞춰 수정한 뒤 화면과 이동 결과를 확인한다. 이 실습은 제안이며 사용자가 수행하거나 이해를 확인한 것으로 기록하지 않는다.
