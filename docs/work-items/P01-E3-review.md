# P01-E3 개발 검토

2026-10-23 / 대상: `1b0f3a5..ac7a4c8`

판정: 명시된 개발 전용 확인 화면과 공통 오류 표시 기반 범위에서 독립 검토 통과. 필수 코드 수정 결함은 발견하지 않았다. 이 세션은 제품·테스트·상태 문서를 변경하지 않고 검토 문서와 요약만 작성했다. 최종 상태 기록·로컬 커밋은 개발세션에서 처리한다.

## 독립 검증

프로젝트 npm.ps1로 test:unit·typecheck·lint·build·test:e2e를 실행했다. [검토 요약](evidence/P01-E3-review-summary.json): DOM **47개 통과**, 타입·린트·빌드 종료 코드 0, Chromium **16개 통과**(desktop/mobile 각각 8개), 실패·skip·flaky 0. 빌드된 JS에서 error-preview·오류 안내 확인·dev/api-errors 문자열도 검색되지 않았다.

Java JAR는 개발세션이 최신 E2로 재빌드한 D4 전용 산출물을 사용했다. Java 69개·기존 Node 68개·RED·순번 방어 제거 실험은 개발세션 기록을 검토했고 여기서 반복하지 않았다. 이번 production dist는 직접 재빌드했다.

| 검토 항목 | 결과 |
| --- | --- |

## 한계·비차단 관찰

- unmount 검사는 abort와 화면 미표시를 확인한다. 해제된 인스턴스의 콜백 호출 수를 직접 계측하지 않는다. 코드의 순번 가드는 별도로 확인했다.
- DOM에서의 잘못된 JSON·연결 실패·취소·늦은 응답 검사는 모의 fetch 기반이다. 실제 네트워크 단절·본문 중단을 새 브라우저 시험으로 재현한 것은 아니다.
- 재시도 키보드 검사는 버튼에 focus() 후 Enter를 누른다. 해당 버튼까지의 전체 Tab 순서나 실제 스크린리더 출력은 검증하지 않는다. 모바일은 에뮬레이션이며 실기기·전체 시각 회귀가 아니다.
- JAR/dist의 최신 여부를 test:e2e가 자동 판정하지 않으므로 재빌드 절차를 지켜야 한다. production 확인은 개발 경로 제외 검사이며 production에서 업무 API 전체 연결을 검증한 것은 아니다.
- 현재 요청 ID는 표시용이며 인증·신뢰 증명·상담 시스템 구현을 뜻하지 않는다. 실제 업무 폼 연결·fieldErrors·자동 재시도는 이번 범위가 아니다. 사용자 직접 실습·이해는 미확인이다.

## 보존

검토 후 읽기 전용 pg_dump에서 무작위 restrict/unrestrict 토큰을 제외한 dev/test 해시가 개발세션 기록과 동일했다. 원문 덤프는 저장하지 않았다. 기존 DB 컨테이너 ID·healthy 및 15432/15433 PID 57168이 유지된다. DB 쓰기·생성·초기화·재시작은 하지 않았다.

기존 8080/4174/5174 앱 리스너는 이전과 같이 없으며 임의 실행·종료하지 않았다. 다음 E 작업·프런트 단순화·push·커밋은 진행하지 않았다.
