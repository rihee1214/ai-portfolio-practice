## 최신 승인 계약

이번 명시 지시가 A 기록의 앞선 정책 대화를 대체한다. 판매자 직접 승인·무회수 환불·30일 기한·첫 부분 환불 배송비 전액 반환을 구현하지 않는다.

1. 원인/귀속이 명확하면 관련 원 수량과 공통 배송비만 보류한다. 무관한 확정 수량·타 매대는 지급 가능하다. 환불/회수비 예약 귀속이 불명확하면 해당 하위 주문 전체를 보류한다. 기존 주간 마감·마감 후 소급 금지·마지막 예약 해제 시각을 유지한다.
2. 원 지급/검토는 불변이며 원 환불에 연결한 조정은1회다. 원 수량 수수료를 반환하고 상품/배송비/회수비를 중복 차감하지 않는다. 같은 매대 후속 양수와 상계하고 부족분을 이월한다. 실제 지급액은0 이상, 타 매대 상계·실제 출금/추심 없음. 매출 없는 주에도 미회수 조정 잔액을 보존·표시한다.
3. 구매확정 후 판매자 책임 하자가 확인된 상품만 예외 환불한다. 기존 운영 문의로 접수하며 일반 반품 재개/확정 상태 되돌림 없음. 거래지원 운영자가 원 주문·수량·문의·하자 확인 근거·사유를 연결해 승인하고 별도 명시 실행한다. 답변만으로 환불하지 않는다. 회수·검수·판매자 책임 확인 필수, 무회수/변심/자유 금액 보상 제외. 원 주문·기존 승인 환불 정책으로 계산하며 판매자 책임 회수비/최초 배송비 조건을 유지한다. 기존 예약·실행·UNKNOWN 조회/복구를 재사용하고 성공액만 조정한다. 별도 자동 신청 기한을 추가하지 않는다.
4. 지급 완료 배치·원장·검토 이력은 보존한다. 시행 이후 생성/명시 재작성한 미지급 초안에 새 정책을 적용한다. 검토 후 명세 변경은 새 버전 재검토를 요구한다. 판매자는 자기 매대 정산·보류·조정·이월만 보며 타 매대 금액/ID/보류 사유는 노출하지 않는다.
