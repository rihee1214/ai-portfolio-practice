찜은 상품 단위 최대100개, 동일 상품 PUT은 멱등, DELETE도 멱등이다. GET /api/wishlist?owner=, PUT /api/wishlist/{slug}?owner=, DELETE /api/wishlist/{productId}?owner=. owner는 principal과 같은 사전조건이며 타인 선택 수단이 아니다. 회원행 잠금 후 BUYER/ACTIVE 재검사로 동시 중복/상한/정지와 직렬화. 상품 공개조회는 catalog API를 사용하며 새 비판매 상품 추가는404, 이미 저장된 비공개/삭제상품은 detail=null로 남겨 삭제 가능. 로컬에는 찜·회원·가격을 저장하지 않는다.

주문서 준비는 현재 장바구니 전체를 storeSlug(승인된 판매자당 매대1개) 기준으로 묶고 상품금액 소계/합계를 보여준다. 빈 장바구니, 확인중/오류, 비판매/품절/재고부족이 하나라도 있으면 준비 내역 진입을 차단한다. /checkout 직접주소/새로고침도 새 cart 조회 후 판정한다. 품목을 임의 제외하거나 주문/예약/결제 완료로 표시하지 않는다. 방문자도 준비 내역을 볼 수 있지만 구매 인증은 P06 이후, 금액은 견적확정이 아니다.
