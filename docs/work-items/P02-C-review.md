# P02-C 독립 검토

2026-10-24 / 기준 `7568a3a` 이후 작업 트리 / 상태: **R1 수정 및 독립 검증 완료, 검토 범위 내 필수 수정 잔여 없음**

## 범위

개발세션의 사용자 직접 승인과 검토 지정을 확인했다. [작업 계획](P02-C.md)의 추가 역할·업무별 운영 권한·최초 운영자 로컬 초기화는 기존 요구사항과 일치한다. ADMIN 시작 공간 접근과 개별 업무 권한을 구분한다. 제품 코드는 수정하지 않았으며, 개발 검증의 임시 포트 사용이 끝난 뒤 새 격리 DB에서 독립 DB·브라우저 검사를 실행했다.

## R1 — URL 변형 시 React 업무 권한 선택 불일치

최초 정적 검토의 `ProtectedWorkspace`는 `location.pathname`과 `workspace.path + '/' + feature.path`를 완전 일치로 비교해 권한을 선택했다. feature를 못 찾으면 ADMIN 공간 권한으로 내려간다. 라우터가 `/admin/users/` 또는 대소문자 변형을 같은 users 라우트로 매칭하면, ACCOUNTS가 필요한 안내 콘텐츠에 ADMIN 공간 검사만 적용되는 구조다.

개발세션에 후행 슬래시·대소문자 변형의 재현과 일관된 매칭 처리를 요청했다. [수정 전 검사](evidence/P02-C-route-red.txt)에서 70개 중 5개 실패·65개 통과를 직접 확인했다. 이 RED는 개발세션 실행 기록이며 이 세션에서 구버전으로 되돌려 실행한 것은 아니다. 수정은 React Router의 matchPath를 사용하여 라우트 매칭과 권한 선택의 의미를 맞췄다. 수정 후 이 세션에서 단위 검사 8파일·70개를 독립 실행해 통과했다.

실제 PC·모바일 브라우저에서도 `/admin/users/`, `/ADMIN/users`, `/admin/sellers/`, `/admin/orders/`의 업무 권한 거부와 `/ADMIN/moderation/`의 CONTENT 권한 허용을 확인했다. **R1 해결 확인.** 실제 업무 API는 별도 서버 권한 검사를 유지하므로 서버 데이터 접근 우회가 확인된 것으로 확대하지 않는다.

## 현재 정적 확인

- JdbcAccessPolicy는 ACTIVE 상태·역할·해당 운영 권한을 DB에서 조회한다. ADMIN만으로 업무 5영역 접근을 허용하지 않는다. 알 수 없는 운영 영역은 null을 통해 거부한다.
- 서버 URL 검사와 AccessController의 서비스용 require가 같은 정책을 사용한다. 실제 승인·정산·소유권 상태 전이 기능이 완성된 것은 아니다.
- InitialAdmin은 DB명·확인값을 확인하고 단일 초기화 행 잠금, 기존 ADMIN 부재, 이메일 확인된 ACTIVE BUYER를 요구한다. 역할·권한5개·감사·authVersion·세션 삭제·완료 표시는 한 트랜잭션이다.
- InitialAdminCommand는 외부 인수를 거부하고, 환경변수 확인 후 web NONE·Flyway false·SQL init never를 명령 옵션으로 고정한다. 기존 스키마가 필요하며 웹 승격 API는 없다. 감사 출처 LOCAL_BOOTSTRAP을 특정 사람의 신원 확인으로 표현하지 않는다.
- WorkspaceAccess는 응답의 영역 일치와 상태를 확인하고, 현재 세션 객체·영역과 다른 늦은 결과를 허용 화면으로 사용하지 않는다. 렌더링 가드는 서버 보안을 대체하지 않는다.

## 한계와 완료 판단

현재 구현 범위의 필수 수정 잔여는 없다. 실제 판매자 승인·콘텐츠 조치·정산 등 업무 기능, 향후 업무 변경과 권한 회수 사이의 동시성, 운영 HTTPS·다중 인스턴스 환경, 사용자의 수동 시연·이해 확인까지 완료한 것으로 보지 않는다. 로컬 초기화 명령은 신뢰된 로컬 실행자와 DB 접근 권한을 전제로 하며 감사 출처가 실행자의 실명 인증을 뜻하지 않는다.

이 검토에서는 제품 코드를 수정하지 않고 검토 문서만 갱신했다. 기존 서버와 DB 데이터, 새 검증 DB를 보존했으며 다음 단계는 진행하지 않았다. 문맥 복원 중 과거 A3 결과를 재보고한 뒤 기존 C 실행 기록과 사용자 승인을 다시 확인하여 이 완료 기록을 마무리했다. 추가 검사를 실행한 것으로 표현하지 않는다.
