# P01-C2 구현 검토

2026-10-23 / 판정: C2 범위 검토 통과. 추가 수정이 필요한 결함은 발견하지 않았다. 사용자 직접 실습 완료는 미확인이고 P01-C3는 미착수다.

## 검토 범위와 근거

개발세션의 구현 커밋 `31542f1`을 C1 완료 커밋 `63dc3c6`과 비교했다. Maven 의존성·출력 경로, 기본/db 프로필, V1 SQL, 실행 안내, 검사 원문과 결과를 대조했다. 이 세션에서 제품 코드와 DB는 변경하지 않았다. 실DB 검사 21개와 프런트 회귀 68개를 여기서 재실행한 것은 아니며 아래 결과는 개발세션 실행 증거를 검토한 것이다.

| 항목 | 검토 결과 |
| --- | --- |
| 의존성·연결 | Boot BOM의 JDBC·Flyway starter, PostgreSQL 모듈·runtime 드라이버를 사용한다. DB 연결은 db 프로필에서 명시적으로 켜며 기본/local 실행에는 요구하지 않는다. JdbcTemplate 업무 조회 구현은 C3 범위다. |
| 단일 초기화 | SQL init은 never이고 Flyway가 지정 스키마와 이력을 관리한다. V1은 스키마 설명만 기록하며 미정 업무 테이블은 추가하지 않았다. clean 금지·자동 baseline 금지 설정이 있다. |
| 최초 이행·재실행 | 최초 로그에서 스키마·이력 생성과 V1 적용을 확인했다. 검사 원문은 성공 V1의 version/description/success와 설명을 비교하고, 재실행 후 이력 및 체크섬이 같은지 확인한다. |
| 실패 구분·복구 | 암호 오류·V1 체크섬 변경·실패 V2는 비정상 종료뿐 아니라 각각 인증 실패·checksum mismatch·division by zero 원인까지 확인한다. 실패 V2의 테이블과 버전 행이 없고 원본 V1으로 복구된다. clean/repair는 호출하지 않았다. |
| 기존 동작 | 기본/local/db의 health 응답을 정확히 200 및 status-only UP으로 검사한다. 초기 프로필 회귀의 실패 기록과 수정 후 결과가 분리돼 있다. |
| 빌드·회귀 | 최종 격리 Maven 빌드 성공, React 타입·린트·빌드 성공, Node 테스트 68개 통과 증거를 확인했다. Java JUnit은 0건이다. 실DB 계약 검사 PASS는 21개이며 마지막 초기화 정책 항목은 설정 파일 검사다. |
| 보존 | 기존 두 DB의 전후 정규화 덤프 해시가 일치한다는 개발 증거를 대조했다. 덤프 생성 자체는 이 세션에서 반복하지 않았다. 검증용 DB 세 개는 보존됐고 원래 개발/테스트 DB에는 V1을 적용하지 않았다. |

## 이 세션의 직접 확인

[읽기 전용 실행 상태 확인](evidence/P01-C2-review-runtime.json)에서 8080과 5174의 `/actuator/health`가 모두 HTTP 200, `{"status":"UP"}`였다. API PID 68748·Vite PID 63940, DB 컨테이너 ID 6a9f494624c9·68d17431a4b1이 유지됐으며 두 컨테이너가 healthy다. 네 포트 8080/5174/15432/15433은 loopback에 바인딩돼 있다. 서버·컨테이너 재시작이나 데이터 삭제는 하지 않았다.

기존 8080 서버는 이전 JAR를 유지한다. 따라서 이 HTTP 확인을 C2 코드가 기존 서버에 배포됐다는 증거로 해석하지 않는다. C2의 DB 연동은 격리 빌드 JAR·전용 DB·임시 앱 프로세스로 검증했다.

## 한계와 반영

clean 호출 차단 자체, 백업 복원, 새 PC/다른 OS, 운영 이행, 사용자 직접 실습 및 업무 SQL·트랜잭션은 검증하지 않았다. UI 브라우저 재검사도 이번 C2에서 수행하지 않았다. 검사 도구는 재실행 시 증거 파일을 덮어쓰고 검증 DB를 남기므로 기존 증거 보존이 필요하면 먼저 복사해야 한다. 기록된 검증 DB 이름 재사용은 새 DB의 최초 이행 검사를 대신하지 않는다.

작업 문서와 계획·현재 상태 안내의 검토 대기를 검토 완료로 갱신했다. 과거 실패 증거는 유지하며 P01-C3는 시작하지 않는다. 검토 문서 및 상태 반영 변경은 구현 커밋과 구분한다.
