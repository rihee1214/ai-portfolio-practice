## 주요 기준

- Java·Spring Boot·PostgreSQL 기반 모듈형 모놀리스 API와 React 화면으로 시작한다. Java·Spring Boot·React는 사용자 확정 선택이며 세부 도구의 근거는 새 ADR-001에 기록한다.
- 화면은 React·TypeScript·Vite·React Router·일반 CSS, DB 접근은 Spring JDBC, DB 변경은 Flyway로 관리한다. Node.js·npm은 React 개발·검증·빌드에 사용한다.
- 개발·테스트용 PostgreSQL은 PC 직접 설치 없이 Docker Compose로 구성한다. 환경 재현과 애플리케이션·DB의 독립 실행, 3계층의 통신 경계 학습이 목적이다. 같은 PC에서 실행 환경을 분리하는 계획이며 별도 물리 서버 구성은 아니다. [선택 이유와 구성 원칙](docs/decisions/ADR-002-docker-postgresql.md)
- 한 저장소의 `backend/`와 `frontend/`로 관리한다. 개발 중에는 Vite의 API 프록시, 공개 환경에서는 같은 출처의 화면·API 경로를 사용한다.
- 상태 확인은 Spring Boot Actuator의 `/actuator/health`를 사용한다. 현재 HTTP에는 health만 노출하고 응답은 status로 제한한다. B4에서 이 경로만 개발 프록시로 연결한다.
- 회원 인증은 Spring Security·Spring Session JDBC의 쿠키 세션과 CSRF 방어를 사용한다. Java 검사는 JUnit Jupiter·MockMvc·실제 PostgreSQL, 화면 검사는 Vitest·React Testing Library·Playwright Test로 나눈다.
- 비회원은 쿠폰 사용 불가, 공개 이벤트 적용 가능이다.
- 비회원은 이름·휴대전화 인증 후 주문 조회 비밀번호를 직접 설정한다.
- 무료 전화 인증 테스트는 Firebase Authentication Emulator를 우선 사용하며 실제 문자는 보내지 않는다.
- 테스트 결제·배송·정산을 제공하고, 실제 판매 운영은 별도 범위다.
- 상품 옵션·이미지, 취소·반품·교환·부분 환불, 문의·신고·모의 정산까지 전체 기능에 포함한다.
- 기본 서비스 완성 후 재현한 문제와 측정 결과를 근거로 한 영역씩 MSA로 전환한다.

## 진행 상태

**[P01-B1 최소 Boot API](docs/work-items/P01-B1.md) 구현·검증 완료.** 기존 `/api/status`를 Actuator의 `GET /actuator/health`로 교체했다. 정상은 200·`{"status":"UP"}`, 검사에서 재현한 장애는 503·`{"status":"DOWN"}`이며 상세 정보는 노출하지 않는다. 빌드와 정상·장애·복구의 HTTP 자동 검사 **27건**이 성공했다. JUnit은 0건이며 사용자 직접 확인은 미확인이다.

프로젝트 전용 JDK 21.0.12.1+1·Maven 3.9.16과 공식 Wrapper 3.3.4를 준비했다. Boot는 4.1.1이다. 시스템 Java·PATH는 변경하지 않았다. 제한된 셸의 DNS 오류와 달리 승인된 외부 실행에서는 다운로드·빌드가 성공했다. 상세 실행 명령과 학습 예시는 P01-B1 기록에 있다.

2026-10-21 Actuator 교체 전 P01-B1 재검증에서는 JDK·Maven ZIP 체크섬 일치, 컴파일·패키징, 기존 HTTP 검사 8건 성공을 확인했다. 이후 health 교체 검증에서도 제한된 환경의 DNS·로컬 통신 오류와 허용된 환경의 성공을 구분했다. 최신 27건 결과와 이전 8건 이력, 아래 B2·B3 결과는 각 작업 기록을 따른다.

**[P01-B2 첫 React 화면](docs/work-items/P01-B2.md)도 완료했다.** 프로젝트 Node 24.22.0·npm 11.19.1로 타입·린트·빌드·잠금 설치를 확인했고 실제 브라우저에서 입력·초기화·한국어 표시를 검증했다. [첫 화면](http://127.0.0.1:5173)은 아래 개발 서버를 실행한 뒤 열 수 있다.

2026-10-21 저녁 B2 재검증에서는 타입·린트·빌드와 보관한 첫 화면 빌드의 UI 조작 10개를 확인했다. PowerShell 실행 명령의 구분자를 `'--'`로 수정했다. 검사 중 별도로 추가된 라우팅·레이아웃 소스는 이 검증 범위에 포함하지 않는다. 자세한 대상·제약·화면 증거는 [B2 재검증 기록](docs/work-items/P01-B2.md)에 있다.

**[P01-B3 경로·공통 레이아웃](docs/work-items/P01-B3.md)을 완료했다.** React Router 8.5.0으로 홈·[구매자](http://127.0.0.1:5173/account)·[판매자](http://127.0.0.1:5173/seller)·[운영자](http://127.0.0.1:5173/admin) 화면 틀과 기능 안내를 연결했다. 타입·린트·빌드 및 직접 URL·새로고침·없는 주소·키보드·375/768/1440px 화면을 확인했다. 사용자 직접 확인은 미확인이다. 모든 역할 화면은 공개 미리보기이며 실제 권한·업무 기능은 미구현이다.

**2026-10-23 P01-B3 최신 내장 브라우저 검증을 완료했다.** 연결 복구 후 정상 경로 16개의 직접 접근·새로고침, 없는 경로 4개, 375/768/1440px 화면, 키보드·모바일 메뉴·입력 회귀를 확인했다. 타입·린트 통과, 앱 코드 변경 없음. [결과와 증거](docs/work-items/P01-B3.md)를 기록했으며 P01-B4는 진행하지 않았다. 결과 확인용 [미리보기](http://127.0.0.1:4174/)는 서버 실행 중 접근할 수 있다.

**[P01-B4 health 연결](docs/work-items/P01-B4.md)의 R4 수정·재검증을 완료했다.** 부분 응답 중단을 브라우저의 연결 오류로 전달하도록 프록시를 보완했다. Node 테스트 68개, 타입·린트·빌드와 개발·preview의 오류·재시도·취소·화면 이탈을 검증했다. 10초는 무활동 제한이며 전체 처리 기한이 아니다. [최신 결과와 이전 실패 증거](docs/work-items/P01-B4-review.md)를 확인한다. 사용자 직접 확인은 미확인이다. 이번 재검증 시작·종료 시 기존 8080·5174 서버는 실행되어 있지 않았고 재시작하지 않았다. P01-B5·DB·인증·업무 API·Git 초기화는 진행하지 않았다.

2026-10-21 개발용 PostgreSQL의 Docker Compose 사용 방침과 선택 이유를 ADR-002에 기록했다. 실제 Compose 구성·컨테이너 실행·DB 연결은 미착수이며 P01-C1 이후에 검증한다.
